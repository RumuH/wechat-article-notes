# 浏览器读取：用户只提供链接

这是智能体调用现有浏览器工具的流程，不是另一个爬虫服务。先阅读宿主浏览器工具文档；只使用本次工具明确支持的 API，不启动未配置的调试端口，不读取浏览器凭据，不增加代理或外部抓取服务。

## 打开并读取

1. 优先复用与用户文章链接匹配的标签页；否则创建一个后台标签页并打开原文链接。Python 收到的验证重定向不能证明正常浏览器也被拦截。
2. 读取页面状态。若有标题和正文，继续；若只有加载中，检查同一标签页，不创建重复标签。如果页面明确显示验证码/登录，请用户仅完成该步骤，随后继续同一页。不要自动绕过验证、登录或付费限制。
3. 默认读取 DOM 快照，确认实际文章标题、开头、章节和末尾。整页可访问性快照有时会超时：检查标签列表确认页面仍存在，然后改用宿主支持的 DOM 快照或针对 `#js_content` 的只读 DOM 读取。超时不是正文不可用的证据。
4. 将 [browser_capture.js](../scripts/browser_capture.js) 的完整文件内容作为函数表达式交给支持的浏览器只读 `evaluate` API。它只读取正文容器、可见元数据、标题结构、图片状态和结束标记；不读取 Cookie、存储、脚本变量或页面请求令牌。
5. 将函数返回的 JSON 原样送入 `python scripts/extract.py` 的 stdin。不手工重写正文，不把 DOM 快照中的按钮、导航或评论当成正文。若宿主支持文件导出，可通过仓库外临时文件传递；不支持导出时使用已有工具的 JSON 数据传递能力，不让用户手工导出。
6. 核对返回值：标题应与页面一致，首尾有正文，章节都在 body 内。捕获字符数是 JavaScript UTF-16 长度，Python 会校验，防止工具输出被截断后被误用。结束标记只证明页面有正文末尾节点，不能保证作者文章本身完整；仍需检查上下文与末章。

## Codex 浏览器工具的已验证调用路径

仅在宿主已返回以下 API 文档时采用；其他宿主使用等价的受支持接口。初始化与浏览器选择遵循宿主规则。取得 `browser` 后：

```js
const tabs = await browser.tabs.list();
// 匹配已有标签页；仅在不存在时使用 tabs.new() + goto(articleUrl)。
const tab = await browser.tabs.get(matchingTab.id);
const snapshot = await tab.playwright.domSnapshot();
// readerSource 是从本 skill 的 scripts/browser_capture.js 读取的完整文本。
const capture = await tab.playwright.evaluate(readerSource);
```

这里使用文档支持的 `browser.tabs` 与 `playwright` 接口，避免把每次取得标签页都和大型自动可访问性快照绑定。变量中的 URL 和 tab id 来自用户输入或实际标签列表，不能写死。

页面快照超时后，在标签列表确认同一页面仍存在，并对同一标签页尝试一次针对正文的读取；必要时再检查一次 DOM 状态。若正文读取也失败，报告浏览器工具故障，不把它误报为微信要求验证。不要反复刷新、无限重试或改写文章 URL。

## 图表与完整性

`images_not_loaded` 表示至少一张图片没有实际加载。微信的 1×1 占位图即使 `complete: true` 也不算加载完成。通过宿主支持的滚动或定位操作让相应图片进入视口，再重新捕获。不要用只读 evaluate 执行滚动或改写页面。

`images_not_read` 表示辅助脚本没有解读图片，即使图片已加载也保留该标记。智能体可使用宿主截图或已观测页面资源读取工具看图；仅有 alt 文本不能宣称读懂图表。图片失败但文字完整时可以继续文字总结，明确缺失图示；图片承载必要内容时请求最小补充。

`browser_end_unconfirmed` 表示未发现 `#js_content_end`。智能体应检查最后一个章节和页面末尾；确实只取得部分正文时才按部分内容处理。不能凭一个结束节点、字符数或文章标题宣称全文完整。

## 私人数据

捕获 JSON 和正文是私人阅读资料，不加入 Git、测试 fixture 或发布包。默认只在当前任务中处理；用户要求保留原文时才另存到其指定的私人目录。开源测试使用合成文章，不能把某次真实阅读链接和内容写入通用 skill。
